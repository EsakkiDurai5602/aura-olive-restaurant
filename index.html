Supabase Connection & Vercel Deployment

Follow these instructions to connect your live Supabase database and deploy this website to Vercel.

Connect Your Supabase Project Directly in Browser:

Enter your Supabase credentials to immediately connect the frontend to your real database.

1

Create Supabase Project & Run SQL Schema

1. Log in to Supabase.com and click New Project.
2. Go to the left navigation bar and click SQL Editor > New Query.
3. Open the file supabase_schema.sql provided in this project root, copy the contents, paste them into the SQL Editor, and click Run. All tables, RLS policies, and seed data will be created automatically.

2

Obtain Your API Credentials

In Supabase, navigate to Project Settings > API.
Copy the Project URL and the anon public key.
You can paste them into the box above or into a .env file: 

SUPABASE_URL=https://your-id.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1Ni...
3

Deploy to Vercel in 2 Minutes

1. Initialize Git and push this repository to GitHub or GitLab:
git add . && git commit -m "Full-stack Restaurant" && git push
2. Open Vercel.com, click Add New... > Project, and import your repository.
3. Under Environment Variables, add:
• SUPABASE_URL: your Supabase URL
• SUPABASE_ANON_KEY: your Supabase Anon key
4. Click Deploy. Vercel automatically deploys the frontend and the serverless Node.js backend using the configured vercel.json!
